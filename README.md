# Biogames

Touchscreenspellen voor biologie, gemaakt voor het digibord (CTOUCH). Online: https://jeleducatie.github.io/biogames/

Het platform werkt hetzelfde als [Mathgames](https://jeleducatie.github.io/mathgames/): jaarlagen → hoofdstukken → spellen, klassen met karakters, scores, Resultaten voor de docent, Klassikaal (stempelkaarten) en Samen spelen.

- Instellingen: houd ⚙ twee seconden vast.
- Gegevens blijven in de browser van het apparaat (los van Mathgames). Gebruik Back-up om ze mee te nemen.
- Nieuwe spellen komen in `index.html` in `GAMES`, hoofdstukken in `SECTIONS`.
